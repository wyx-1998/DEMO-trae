# 移动端设计指南

## 项目概述

本项目是**中建材安全管理系统**的移动端应用，主要服务于企业安全生产管理、危险物品管理、工作场所管理等B端业务场景。

## 设计原则

### 1. 效率优先
- 减少操作步骤，3步内完成核心任务
- 提供快捷操作（快捷审批、一键提交）
- 支持批量操作
- 智能填充和自动计算

### 2. 精致视觉
- **色彩克制**：主题色为主，功能色为辅，避免渐变色泛滥
- **阴影层级**：卡片阴影要轻量（0 2px 8px rgba），避免过重
- **图标统一**：使用emoji或统一图标库，大小一致（20-24px）
- **间距呼吸**：模块间距≥16px，卡片内边距≥16px

### 3. 交互友好
- **状态清晰**：每个按钮必须有hover/active/disabled状态
- **反馈及时**：操作后立即toast提示，加载显示skeleton
- **容错设计**：重要操作二次确认，支持撤销
- **手势自然**：支持下拉刷新、侧滑操作

### 4. 场景适配
- 考虑单手操作（重要按钮在底部）
- 减少文字输入（选择器、扫码、OCR）
- 弱网环境优化（离线缓存、数据预加载）
- 碎片化时间使用（快速查看、快速操作）

## 导航模式

### 底部Tab导航
- **适用场景**：功能3-5个，需要快速切换
- **设计要点**：
  - 图标+文字组合
  - 当前选中状态明显
  - 支持角标提示
  - 高度56px

### 顶部导航
- **适用场景**：单一任务流，需要聚焦流程
- **设计要点**：
  - 左侧返回按钮
  - 中间标题居中
  - 右侧操作按钮
  - 高度44px

### 工作台宫格+Tab
- **适用场景**：功能8+个，需要分层清晰
- **设计要点**：
  - 4列宫格布局
  - 功能分组展示
  - 支持自定义排序
  - 卡片式设计

## 页面类型设计

### 1. 工作台首页
```
布局结构：
- 顶部：企业名称 + 搜索 + 更多
- 待办提醒：数字角标
- 功能宫格：4列布局
- 功能分组：工作台/管理/业务
- 底部Tab：首页/消息/应用/我的
```

### 2. 列表页面
```
布局结构：
- 顶部筛选：待审批/已审批
- 卡片列表：标题+发起人+时间+状态
- 下拉刷新：加载最新数据
- 侧滑操作：同意/拒绝
- 底部加载更多
```

### 3. 详情页面
```
布局结构：
- 顶部导航：返回+标题
- 审批内容：表单展示
- 审批流程：时间轴可视化
- 审批历史：操作记录
- 底部操作：同意/拒绝/转交
```

### 4. 表单页面
```
布局结构：
- 表单分组：基本信息/详细信息
- 必填标识：红色星号
- 输入辅助：日期选择/地址选择/拍照
- 实时验证：错误提示
- 底部操作：保存草稿/提交
```

## 响应式设计

### 断点设置
```css
/* 移动端 */
@media (max-width: 576px) {
  /* 手机端样式 */
}

/* 平板端 */
@media (min-width: 577px) and (max-width: 768px) {
  /* 平板端样式 */
}

/* 小屏手机 */
@media (max-width: 320px) {
  /* 小屏适配 */
}
```

### 适配原则
- 字体大小：最小12px，最大20px
- 触控区域：最小44px
- 图片响应式：max-width: 100%
- 弹性布局：flexbox为主
- 安全区域：考虑刘海屏、底部手势

## 动效设计

### 过渡动画

```css
  transition: all 0.2s ease;

  transform: translateY(-2px);

}

/* 按钮点击 */
.button-active:active {
  transform: scale(0.98);
  transition: transform 0.1s ease;
}
```

### 加载动画
```css
/* 骨架屏 */
.skeleton {
  background: linear-gradient(90deg, #f0f0f0 25%, #e0e0e0 50%, #f0f0f0 75%);
  background-size: 200% 100%;
  animation: loading 1.5s infinite;
}

@keyframes loading {
  0% { background-position: 200% 0; }
  100% { background-position: -200% 0; }
}
```
