## 建设项目
使用人
* 查看
    * 建设项目安全管理人员、领导
* 更新项目进展、上传安全管理资料
    * 建设项目安全管理人员
<!-- -->

主要功能点
1. 实现建设项目基础信息的建立与申报；
2. 实现建设项目安全设施三同时、职业健康三同时、消防三同时和其他安全管理资料的在线维护管理
<!-- -->

页面设计
* 列表
    * tab
        * 建设中
        * 已竣工
        * 申报中
        * 草稿
    * 功能按钮
        * 新建
            * 打开新建建设项目页面
    * 查询条件
        * 项目编号
        * 项目名称
        * 项目管理类型
            * EPC（工程总承包）
            * EPCM（工程总承包）
            * PC（采购-施工承包）
            * C（施工总承包）
            * EMC（合同能源管理）
            * DB（设计-施工）
            * CM（施工管理）
            * PMC（项目管理承包）
            * 其他
        * 建设类别
            * 工业建筑
            * 民用建筑
            * 商用建筑
        * 建设性质
            * 新建
            * 扩建
            * 改建
            * 迁建
            * 恢复
            * 其他
        * 业主单位（发包方）
        * 实施单位（承包方）
        * 是否纳入安全管理
            * 是
            * 否
    * 列表字段
        * 项目编号、项目名称、项目管理类型、建设类别、建设性质、项目状态（建设中、已竣工、申报中、草稿）、业主单位（发包方）、实施单位（承包方）、是否纳入安全管理、计划开工日期、实际开工日期、计划竣工日期、实际竣工日期、当前进展阶段、完成百分比（%）
    * 操作按钮
        * 查看
            * 打开建设项目详情的查看页面
        * 编辑
            * 打开建设项目详情的编辑页面
        * 更新项目进度
            * 打开更新项目进度的弹窗
        * 上传安全管理资料
            * 打开上传安全管理资料的弹窗
        * 删除
            * 打开确认删除建设项目的二次确认弹窗
* 详情
    * 基本信息
        * 项目编号
        * 项目名称
        * 统计年份
        * 项目管理类型
            * EPC（工程总承包）
            * EPCM（工程总承包）
            * PC（采购-施工承包）
            * C（施工总承包）
            * EMC（合同能源管理）
            * DB（设计-施工）
            * CM（施工管理）
            * PMC（项目管理承包）
            * 其他
        * 建设类别
            * 工业建筑
            * 民用建筑
            * 商用建筑
        * 建设性质
            * 新建
            * 扩建
            * 改建
            * 迁建
            * 恢复
            * 其他
        * 项目投资（万元）
        * 经纬度坐标
            * 查询坐标（点击跳转至高德开放平台获取坐标）
        * 项目地址（长文本）
        * 项目概况（长文本）
        * 计划开工日期
        * 计划竣工日期
        * 是否纳入安全管理
            * 是
                * 需要进行审批，审批通过后将系统自动创建该建设项目组织及安全管理部门等
            * 否
        * 项目单位
            * 列字段
                * 单位类型、组织类型（内部组织/外部组织）、单位名称、项目负责人、联系方式
            * 行
                * 业主单位（发包方）
                * 实施单位（承包方）
        * 其他相关单位
            * 列字段
                * 单位类型、组织类型（内部组织/外部组织）、单位名称、项目负责人、联系方式
            * 行
                * 管理单位
                * 设计单位
                * 监理单位
                * 地勘单位
        * 项目资料
            * 附件上传
            * 功能按钮
                * 查看
                    * 打开新页面预览查看文件
                * 下载
    * 项目进展
        * 项目状态（建设、竣工）
        * 实际开工日期
        * 实际竣工日期
        * 项目完成百分比
            * 进度条+数字组合展示
        * 当前进展阶段（长文本）
    * 项目安全管理资料
        * tab
            * 安全设施三同时
            * 职业健康三同时
            * 消防三同时
            * 其他安全管理资料
        * 左侧
            * 支持自定义的两级节点树
            * 预设节点
                * 安全设施三同时
                    * 设计阶段
                    * 施工阶段
                    * 使用阶段
                * 职业健康三同时
                    * 可行性论证阶段
                    * 设计阶段
                    * 验收阶段
                * 消防三同时
                    * 设计阶段
                    * 验收阶段
                * 其他安全管理资料
        * 右侧
            * 查询条件
                * 文件名
            * 列表
                * 所属节点
                * 附件名称
                * 上传人
                * 上传时间
                * 操作按钮
                    * 查看、下载、删除
        * 功能按钮
            * 上传附件
            * 批量删除
            * 批量下载
            * 批量设置
                * 打开弹窗为批量设置选中的文件所属节点
    * 其他功能
        * 提交审批
            * 是否纳入安全管理选择“是”的建设项目需要提交审批，审批通过后自动创建建设项目组织
* 更新项目进度的弹窗
    * 项目状态（建设、竣工）
    * 实际开工日期
    * 实际竣工日期
    * 项目完成百分比
        * 进度条+数字组合展示
    * 当前进展阶段（长文本）
    * 功能按钮
        * 关闭
        * 保存
* 上传安全管理资料的弹窗
    * 类型
        * 安全设施三同时
        * 职业健康三同时
        * 消防三同时
        * 其他安全管理资料
    * 所属节点
    * 附件上传
    * 功能按钮
        * 取消
        * 确认
