# 危险物品管理系统需求分析文档

## 1. 角色信息分析

| 角色名称 | 角色描述 | 权限范围 | 关注重点 |
|---------|---------|---------|---------|
| 安全管理员 | 负责危险化学品建库、录入、初审和风险辨识 | 台账录入、MSDS/标签上传、风险档案编制、初审 | 合规性、数据准确性、风险辨识完整性 |
| 部门负责人 | 负责风险档案和控制措施的复审与发布 | 复审、发布、控制措施审核 | 风险控制有效性、措施可行性 |
| 企业主要负责人 | 负责最终审批和发布决策 | 最终审批、发布决策 | 合规性、企业安全责任 |
| 仓储/物料管理员 | 负责危险化学品的出入库操作和储量维护 | 出入库登记、库存更新、储存位置管理 | 库存准确性、双人制度执行 |
| 应急与培训人员 | 负责MSDS/标签的合规核查与应急培训 | MSDS/标签查阅、合规性校验、培训记录 | 应急响应准确性、标签有效性 |
| IT/资料管理员 | 负责系统维护、版本管理和审计留痕 | 版本管理、数据归档、操作日志 | 数据不可篡改、历史追溯 |
| 一般员工（移动端） | 通过移动端查阅MSDS和安全标签 | 扫码查询、只读查看 | 快速获取安全信息 |

## 2. 菜单设计

```
一级菜单：危险物品管理
├── 二级菜单：危险化学品信息库（安全管理员、应急人员、查阅权限：所有角色）
│   ├── 化学品清单
├── 二级菜单：危险化学品台账（安全管理员、仓储管理员、查阅权限：所有角色）
│   ├── 化学品清单
├── 二级菜单：危险废物台账（安全管理员、仓储管理员）
│   ├── 危废清单
│   ├── 暂存管理
│   └── 处置记录
├── 二级菜单：安全风险分布档案（安全管理员编制、部门负责人审核、企业负责人审批）
│   ├── 档案编制
│   ├── 审批流程
│   └── 已发布档案
├── 二级菜单：统计报表（管理层、安全管理员）
│   ├── 危险化学品统计
│   ├── 危险废物统计
└── 二级菜单：移动端（所有角色）
    ├── 扫码查询MSDS
    └── 化学品快速检索
```

## 3. 页面设计

### 3.1 危险化学品信息（预设标准表）

#### 页面定位
- **页面名称**：危险化学品信息库
- **页面类型**：列表页（预设标准数据）
- **页面目标**：维护危险化学品的标准信息和法规属性，作为台账引用的基础数据

#### 页面布局
- **顶部区域**：搜索筛选（化学品名称、CAS号、危险性分类、是否剧毒、是否易制爆）
- **中部区域**：化学品信息列表，支持排序和分页
- **右侧区域**：操作按钮（新增、编辑、导入标准库、导出）
- **底部区域**：分页器

## 4. 数据字典

### 4.1 通用字典

- 计量单位：mg、g、kg、t、mL、L、m³
- 数据来源：手动录入、标准库导入、API获取
- 库存状态：正常、超期、冻结
- 复核周期：年度、半年度、季度
- 包装检查状态：完好、破损、待检

### 4.2 危险化学品信息（预设标准表）字典

- 物理危险（GB 30000.1-2024）：爆炸物、易燃气体、易燃液体、易燃固体、自反应物质/混合物、自燃液体、自燃固体、遇水放出易燃气体物质、氧化性气体、氧化性液体、氧化性固体、有机过氧化物、腐蚀性物质、高压气体
- 健康危害：急性毒性（经口/经皮/吸入）、皮肤腐蚀/刺激、严重眼损伤/眼刺激、呼吸道致敏/皮肤致敏、生殖细胞致突变性、致癌性、生殖毒性、特异性靶器官毒性（一次/重复）、吸入危害
- 环境危害：危害水生环境（急性/慢性）
- GHS象形图（8种）：爆炸、火焰、氧化剂、气瓶、腐蚀、骷髅、感叹号、健康危害
- 信号词：Danger、Warning
- 推荐包装类型：金属桶、玻璃瓶、塑料桶、高压气瓶、IBC吨桶、试剂瓶
- 推荐包装材质：不锈钢、玻璃、PE、PP、PVC、PET

### 4.3 危险化学品台账字典

- 包装类型：200L铁桶、25kg编织袋、IBC吨桶、气瓶、玻璃瓶、塑料桶
- 包装材质：不锈钢、碳钢内衬、玻璃、PE、PP、复合材料
- 标签状态：已粘贴、未粘贴、破损

### 4.4 危险废物台账字典

- 危废代码：HW01–HW49（符合2021版名录，系统维护全量）
- 容器类型：桶、罐、袋、箱、IBC吨桶、气瓶
- 计量单位：kg、吨、m³
- 暂存状态：暂存中、已转移、已处置

### 4.5 法规/映射字典

- H代码（危险说明）：按GB 30000映射，示例：H225 易燃液体和蒸气
- P代码（防范说明）：按GHS映射，示例：P210 远离热源
- UN编号：4位数字，按联合国危险货物清单维护
