# 危险化学品安全风险分布档案页面设计

## 1. 页面定位

- **页面名称**：危险化学品安全风险分布档案
- **页面类型**：综合管理页面（列表+统计+详情）
- **页面目标**：按区域/单元维度进行危险化学品风险聚合分析，执行GB18218重大危险源判定规则，实现自动化的风险评估和预警管理

## 4. 业务流程设计

### 4.1 风险计算触发机制

```
触发条件：
1. 危险化学品台账新增/修改/删除 → 实时触发
2. 区域设置变更 → 触发重新计算
3. 化学品标准库临界量变更 → 批量触发
4. 定时任务（每日凌晨2点）→ 全量重算

计算逻辑：
1. 按"储存单元"聚合危化品台账数据
2. 获取各化学品的临界量Q_i
3. 计算单品种判定：q_i/Q_i ≥ 1
4. 计算多品种累加：Σ(q_i/Q_i) ≥ 1
5. 生成风险档案记录
6. 触发重大危险源模块同步
7. 发送变更通知（如适用）
```

### 4.2 数据同步机制

```
数据流向：
危险化学品台账 → 安全风险分布档案 → 重大危险源管理

同步规则：
1. 增量同步：5分钟检查一次变更
2. 实时同步：关键操作立即触发
3. 全量校验：每日全量数据一致性检查
4. 异常处理：数据不一致时自动告警
```

## 7. 技术实现要点

### 7.1 性能优化

- **缓存机制**：风险计算结果缓存5分钟
- **异步处理**：大批量数据计算采用异步任务
- **分页查询**：支持大数据量分页展示
- **索引优化**：区域编码、时间字段建立索引

### 7.2 数据一致性

- **事务控制**：确保危化品台账与风险档案数据一致
- **版本管理**：保留风险判定历史版本，支持追溯
- **校验机制**：定期进行数据一致性检查

### 7.3 用户体验

- **实时反馈**：操作后立即显示计算进度
- **进度指示**：大批量计算显示进度条
- **友好提示**：异常情况提供清晰的错误信息和解决建议
