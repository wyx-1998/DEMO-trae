# 安全预算和投入页面设计文档

## 1. 功能概述

主要用于管理企业内安全投入预算的编制，包括公司级投入预算和部门级投入预算，跟踪各类别的实际投入情况。

## 2. 用户权限

### 2.1 使用人员
- **查看权限**: 安全管理人员、安全员
- **编辑权限**: 安全管理人员、运维人员

## 3. 主要功能点

- 安全预算：编制公司级投入预算
- 安全投入：维护各项目实际投入

## 4. 页面设计

### 4.1 安全预算

#### 4.1.1 列表

1. 主操作区
   1. 新建：打开安全预算详情页新建数据
   2. 批量删除：批量删除已选择的数据
   3. 导出：导出当前列表数据为excel文件
2. 查询区域
   1. 提取周期：年份选择器
3. 列表
   1. 字段
      1. 编号
      2. 预算时间
      3. 投入预算（万元）：千分号间隔，6位小数
      4. 更新人
      5. 更新时间
   2. 操作按钮
      1. 查看
      2. 编辑
      3. 删除

#### 4.1.2 详情页

表单内容为三列布局

1. 基础数据

   | 字段名称           | 类型       | 是否必填 |      | 备注                          |
   | ------------------ | ---------- | -------- | ---- | ----------------------------- |
   | 编号               | 文本输入框 | 是（*）  |      | 不可编辑，默认为AQYS-2026-001 |
   | 预算时间           | 年份选择器 | 是（*）  |      | 默认显示2026年                |
   | 预算总金额（万元） | 文本输入框 | 是（*）  |      | 6位小数，千分号间隔           |

2. 详细预算

   列表形态展示

   - 字段
     - 序号
     - 投入类别名称：显示投入类别列表的投入类别名称，按照排序号顺序排序
     - 计划投入费用（万元）：显示计划编制的金额，不可编辑
     - 投入预算（万元）：文本输入框，6位小数，需要有千分号间隔

3. 按钮

   1. 取消
   2. 保存

### 4.2 安全投入

#### 4.1.1 列表

1. 主操作区
   1. 新建：打开安全投入详情页新建数据
   2. 批量删除：批量删除已选择的数据
   3. 导出：导出当前列表数据为excel文件
2. 查询区域
   1. 项目名称
   2. 是否两措：默认为空，下拉选项为安措、反措、其他
   3. 实际完成时间：日期范围选择器
3. 列表
   1. 字段
      1. 编号
      2. 项目名称
      3. 所属类别
      4. 是否两措：安措、反措、其他
      5. 实际完成时间
      6. 实际投入费用（万元）
      7. 责任单位（部门）
      8. 责任人
   2. 操作按钮
      1. 查看
      2. 编辑
      3. 删除

#### 4.1.2 详情页

表单内容为三列布局

1. 基础数据

   | 字段名称             | 类型       | 是否必填 | 备注                                                         |
   | -------------------- | ---------- | -------- | ------------------------------------------------------------ |
   | 编号                 | 文本输入框 | 是（*）  | 不可编辑，默认为AQTR-20260101-001                            |
   | 是否两措             | 下拉框     | 是（*）  | 下拉选项为：安措、反措、其他。默认选择“安措”                 |
   | 项目名称             | 文本输入框 | 是（*）  | 选择来源，来源投入计划管理内的安措计划、反措计划和其他计划。默认显示“现场消防设备维护保养” |
   | 所属类别             | 文本输入框 | 是（*）  | 不可编辑，独占一行，默认显示“消防设施维护及检测”             |
   | 项目内容             | 文本域     | 是（*）  | 不可编辑，独占一行，默认显示“检查现场消防设备并进行维修保养，确保消防设备正常” |
   | 计划完成时间         | 日期选择器 | 是（*）  | 不可编辑，默认显示“2026-01-05”                               |
   | 计划投入费用（万元） | 文本输入框 | 是（*）  | 不可编辑，默认显示“8”                                        |
   | 责任单位（部门）     | 文本输入框 | 是（*）  | 不可编辑，默认显示“设备部”                                   |
   | 责任人               | 文本输入框 | 是（*）  | 不可编辑，默认显示“张三”                                     |

2. 实际投入

   | 字段名称             | 类型       | 是否必填 | 备注                                |
   | -------------------- | ---------- | -------- | ----------------------------------- |
   | 实际投入时间         | 日期选择器 | 是（*）  | 默认显示系统当前日期                |
   | 实际投入费用（万元） | 文本输入框 | 是（*）  | 输入为数字，6位小数，需要千分号分隔 |
   | 备注                 | 文本域     | 否       | 独占一行，字数限制0/500             |
   | 附件                 | 附件上传   | 否       |                                     |

3. 按钮

   1. 取消
   2. 保存
