# 安全费用计提管理页面设计文档

## 1. 功能概述

主要用于管理企业内安全投入费用的计提

## 2. 用户权限

### 2.1 使用人员

- **查看权限**: 安全管理人员、安全员
- **编辑权限**: 安全管理人员、运维人员

## 3. 主要功能点

- 计提管理：根据行业标准提取安全费用

## 4. 页面设计

### 4.1 列表

#### 4.1.2 主操作区

- 新建：打开详情页新建数据
- 批量删除：批量删除已选择的数据
- 导出：导出当前列表数据为excel文件

#### 4.1.3 查询区域

- 字段
  - 提取周期：年份选择器

#### 4.1.4 列表字段

- 提取周期
- 投入预算（万元）：千分号间隔，6位小数
- 更新人
- 更新时间
- 操作按钮
  - 查看
  - 编辑
  - 删除


### 4.2 详情页

表单内容为三列布局

#### 4.2.1基础数据

| 字段名称     | 类型       | 是否必填 |      | 备注                               |
| ------------ | ---------- | -------- | ---- | ---------------------------------- |
| 编号         | 文本输入框 | 是（*）  |      | 不可编辑，默认为AQTRJH-2026-001    |
| 组织名称     | 文本输入框 | 是（*）  |      | 不可编辑，默认为xx电力             |
| 所属行业类型 | 文本输入框 | 是（*）  |      | 不可编辑，默认为电力生产与供应企业 |
| 提取类型     | 文本输入框 | 是（*）  |      | 不可编辑，默认为电力生产企业       |
| 提取规则类型 | 下拉框     | 是（*）  |      | 不可编辑，默认为超额累退           |
| 提取周期类型 | 下拉框     | 是（*）  |      | 不可编辑，默认为年度分摊提取       |
| 提取周期     | 年份选择器 | 是（*）  |      | 默认为当前年                       |

#### 4.2.2 提取数据

| 字段名称                   | 类型       | 是否必填 | 备注                                                         |
| -------------------------- | ---------- | -------- | ------------------------------------------------------------ |
| 提取依据名称               | 文本输入框 | 是（*）  | 不可编辑，默认显示“上一年度营业收入（万元）”                 |
| 提取依据值                 | 输入框     | 是（*）  | 输入值为金额，两位小数，需要有千分号间隔数据，默认数据为“150000” |
| 本周期应提取金额（万元）   | 输入框     | 是（*）  | 不可编辑，根据提取类型所属的详细提取规则，根据提取依据值自动计算 |
| 本周期计划投入预算（万元） | 输入框     | 是（*）  | 不可编辑，默认数据为“145000”                                 |
| 上一周期结余金额（万元）   | 输入框     | 是（*）  | 输入值为金额，两位小数，需要有千分号间隔数据，默认数据为“50000” |
| 本周期计提金额（万元）     | 输入框     | 是（*）  | =本周期应提取金额+上一周期结余金额                           |

#### 4.2.3 详细计划

- 列表形态展示
  - 字段
    - 序号
    - 投入类别名称：根据“提取类型”显示投入类别列表的投入类别名称，按照排序号顺序排序
    - 本周期计划投入费用（万元）：6位小数的数字，不可编辑，需要有千分号间隔
    - 本周期计提金额（万元）：输入框，6位小数，需要有千分号间隔

#### 4.2.4 按钮

- 按钮
  - 取消
  - 保存
