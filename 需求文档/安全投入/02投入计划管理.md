# 投入计划管理设计文档

## 1. 功能概述

主要用于管理企业内安全投入不同类型（安措、反措和其他）的计划编制。

## 2. 用户权限

### 2.1 使用人员
- **查看权限**: 
- **编辑权限**: 

## 3. 主要功能点

- 安措计划：编制安全技术和劳动保护措施投入计划，实际投入跟踪
- 反措计划：编制反事故措施投入计划，实际投入跟踪
- 其他计划：编制其他投入计划，实际投入跟踪

## 4. 页面设计

### 4.1 安措计划

#### 4.1.1 列表

1. 主操作区
   1. 新建：打开安措计划详情页
   2. 批量删除：批量删除所选数据
   3. 导入：导入excel文件
   4. 导出：导出表格数据为excel文件
2. 查询区域
   1. 投入类别：下拉框
   2. 项目名称：模糊搜索
   3. 责任单位（部门）：下拉框
   4. 责任人：模糊搜索
   5. 计划完成时间：日期范围选择器
3. 列表
   1. 字段
      1. 投入类别
      2. 项目编号
      3. 项目名称
      4. 项目内容
      5. 计划完成时间
      6. 计划投入费用（元）
      7. 责任单位（部门）
      8. 责任人
   2. 操作按钮
      1. 查看
      2. 编辑
      3. 删除

#### 4.1.2 详情页

表单内容为三列布局

1. 模块名称

   | 字段名称             | 类型       | 是否必填 | 备注                                     |
   | -------------------- | ---------- | -------- | ---------------------------------------- |
   | 项目编号             | 文本输入框 | 是（*）  | 默认为：AQTRJH-20260101-0001，不允许编辑 |
   | 所属类别             | 下拉框     | 是（*）  | 默认为：安全标志                         |
   | 项目名称             | 文本输入框 | 是（*）  |                                          |
   | 项目内容             | 文本域     | 是（*）  | 独占一行，字数限制0/200                  |
   | 计划完成时间         | 日期选择器 | 是（*）  |                                          |
   | 计划投入费用（万元） | 文本输入框 | 是（*）  | 输入限制为数字，6位小数，千分号分割      |
   | 责任单位（部门）     | 下拉框     | 是（*）  | 默认为：设备部                           |
   | 责任人               | 文本输入框 | 是（*）  | 默认为：张三                             |
   | 备注                 | 文本输入域 | 否       | 独占一行，字数限制0/200                  |

2. 操作按钮

   1. 取消
   2. 保存
