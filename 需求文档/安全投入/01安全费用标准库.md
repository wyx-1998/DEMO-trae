# 安全费用标准库页面设计文档

## 1. 功能概述

主要用于管理集团内不同企业类型的安全生产费用提取标准、支出范围、负面清单，提供后续安全生产费用的自动计算规则和费用支出范围的选择。

## 2. 用户权限

### 2.1 使用人员
- **查看权限**: 各组织安全管理人员、安全员
- **编辑权限**: 集团安全管理人员、运维人员

## 3. 主要功能点

- 计提标准库：各企业类型安全生产费用的提取标准
- 投入类别库：各企业类型安全生产费用的投入类别范围标准

## 4. 页面设计

### 4.1 计提标准库列表

#### 4.1.1 行业树

- 内置行业树，如下：
  - 安全投入企业分类
    - 煤炭生产企业
    - 非煤矿山开采企业
    - 石油天然气开采企业
    - 建设工程施工企业
    - 危险品生产与存储企业
    - 交通运输企业
    - 冶金企业
    - 机械制造企业
    - 烟花爆竹生产企业
    - 民用爆炸物品生产企业
    - 武器装备研制生产与实验企业
    - 电力生产与供应企业
    - 其他企业

#### 4.1.2 主操作区

- 新建：打开详情页新建数据
- 批量删除：批量删除已选择的数据

#### 4.1.3 查询区域

- 字段
  - 提取类型：模糊搜索

#### 4.1.4 列表字段

- 编码
- 所属行业类型
- 提取类型
- 提取周期类型：月度实时提取、年度分摊提取、项目进度提取
- 提取依据名称
- 提取规则类型：比例提取、超额累退

### 4.2 计提标准库详情页

表单内容为三列布局

#### 4.2.1基本信息

| 字段名称     | 类型       | 是否必填 | 备注                             |
| ------------ | ---------- | -------- | -------------------------------- |
| 编码         | 文本输入框 | 是（*）  | 编码规则：AQTR-0001，4位自增序号 |
| 所属行业类型 | 下拉选择器 | 是（*）  | 选择安全投入企业分类             |
| 提取类型     | 文本输入框 | 是（*）  |                                  |

#### 4.2.2 详细提取规则

| 字段名称     | 类型       | 是否必填 | 备注                                             |
| ------------ | ---------- | -------- | ------------------------------------------------ |
| 提取周期类型 | 下拉选择器 | 是（*）  | 字典项：月度实时提取、年度分摊提取、项目进度提取 |
| 提取规则类型 | 下拉选择器 | 是（*）  | 字典项：比例提取、超额累退                       |
| 提取依据名称 | 文本输入框 | 是（*）  |                                                  |

- 提取规则类型为比例提取时
  - 列表形态展示
  - 字段名称为：序号、提取依据名称、提取比例（%）
- 提取规则类型为超额累退时
  - 列表形态展示
  - 字段名称为：序号、上限、下限、提取比例（%）

#### 4.2.3 投入范围

- 按钮
  - 添加：弹窗方式添加新的投入类别
  - 删除：批量删除选择的数据
- 表格形态展示
  - 字段名称为：编号、投入类别名称、排序号

#### 4.2.4 单位配置

- 按钮
  - 添加：打开多选组织弹窗
  - 删除：删除批量选择的组织数据
- 列表形态展示已选择的组织
  - 字段名称为：组织简称、组织名称、组织类别

### 4.3 投入类别库列表

#### 4.3.1 行业树

- 同计提标准库的行业树，为同一棵树

#### 4.3.2 主操作区

- 新建：打开弹窗新建数据
- 批量删除：批量删除已选择的数据

#### 4.3.3 查询区域

- 投入类别名称：模糊搜索

#### 4.3.4 列表字段

列表以树的结构展示

- 安全投入行业分类
- 排序号
- 投入类别名称
- 两措属性：安措、反措、其他

### 4.4 投入类别库弹窗

- 弹窗内为单列
- 弹窗名称：新建投入类别
- 弹窗内字段：
  - 安全投入行业分类：下拉框，下拉面板内容行业树，必填
  - 排序号：非必填
  - 投入类别名称：长文本输入框，0/200，必填
  - 上级投入类别：下拉框，非必填，根据所选安全投入行业分类显示所选行业分类下的投入类别树
  - 两措属性：非必填，下拉框，下拉选项为：安措、反措、其他
- 弹窗按钮
  - 取消
  - 保存并关闭
