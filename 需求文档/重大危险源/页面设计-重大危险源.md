# 重大危险源模块 页面设计说明

## 1. 角色信息分析

| 角色名称 | 角色描述 | 权限范围 | 关注重点 |
|---------|---------|---------|---------|
| 企业主要负责人 | 负责总体管理与公示承诺 | 查看全量、审批备案提交、更新承诺公告 | 合规、公示、履职达标 |
| 技术负责人 | 负责技术管理与监测接入、季度排查 | 新建/编辑台账、配置监测、维护排查记录 | 辨识准确、监测在线、评估闭环 |
| 操作负责人 | 负责现场管理与每周排查 | 查看与维护排查记录、处理预警 | 现场风险控制、问题闭环 |
| 安全管理机构 | 负责建档备案、资料留存 | 备案提交、附件维护、状态同步 | 备案一致性、资料完整性 |
| 子公司本部（监管） | 督办与汇总评价 | 查看统计、督办提醒、导出报表 | 履职与合规达标率 |

## 2. 菜单设计
- 一级菜单：`重大危险源管理`
  - 二级菜单：`重大危险源台账`（列表/详情）
  - 二级菜单：`新建/编辑重大危险源`
  - 二级菜单：`在线监测与预警`
  - 二级菜单：`包保履职记录`
  - 说明：关联视图（隐患、应急预案与演练、状态变更与核销）均嵌入到具体业务页面中展示，不单列为二级菜单。

权限分配（示例）：
- 主要负责人：查看全部、备案提交、承诺公告更新
- 技术负责人：新建/编辑、监测配置、季度排查记录维护
- 操作负责人：查看、每周排查记录维护、预警处置记录维护
- 安全管理机构：备案提交、附件与资料维护、状态同步
- 子公司本部：查看统计与督办、导出报表

## 3. 页面设计

### 3.1 台账列表页
- 页面类型：列表页
- 页面目标：查询筛选重大危险源、快速查看状态并进入详情/编辑
- 页面布局：
  - 顶部搜索区：关键字、企业/单元、危险化学品类别、风险等级、状态筛选
  - 中部列表区：数据表格+状态色标
  - 底部操作区：分页、导出
- 字段设计：

| 字段名称 | 字段类型 | 是否必填 | 字段说明 | 数据来源 | 约束规则 |
|---------|---------|---------|---------|---------|---------|
| 重大危险源编号 | 文本 | 是 | 备案编号/企业内部编号 | 台账 | 唯一 |
| 所属单元 | 下拉 | 是 | 生产/储存/使用/搬运 | 字典（GB18218） | 固定枚举 |
| 危险化学品名称 | 文本 | 是 | 名称（含CAS） | 台账 | ≤100字符 |
| 临界量判定 | 枚举 | 是 | ≥临界量/＜临界量 | 计算结果 | 只读显示 |
| 风险等级 | 枚举 | 是 | 可容许/超限（四色图） | 字典 | 色彩映射 |
| 包保责任人 | 复合 | 是 | 主要/技术/操作三类 | 组织通讯录/台账 | 三类均需有值 |
| 备案日期 | 日期 | 是 | 最近备案/更新日期 | 备案记录 | 合法日期 |
| 监测接入状态 | 枚举 | 是 | 已接入/未接入 | 监测系统 | 只读显示 |
| 状态 | 枚举 | 是 | 在册/变更中/核销中/已核销 | 外部流程同步 | 只读显示 |
- 页面操作：查看详情、编辑、导出、筛选/排序、列显隐、批量导出
- 交互说明：
  - 风险等级与状态使用色标显示；筛选条件与列表联动
  - 点击“状态”字段可打开“状态变更与核销引用视图”（只读）

### 3.2 台账详情页
- 页面类型：详情页
- 页面目标：完整查看台账信息与关联记录，进行必要的资料维护
- 页面布局：
  - 基本信息卡：编号、单元、化学品、临界量与判定、风险等级
  - 包保与公示卡：三类责任人、公示牌位置与照片、承诺公告链接
  - 监测接入卡：指标点清单、阈值、接入状态
  - 备案信息卡：属地部门、报备日期、登记系统ID
  - 关联视图：隐患信息引用、应急预案与演练引用、状态变更与核销引用
- 字段设计（关键字段）：

| 字段名称 | 字段类型 | 是否必填 | 字段说明 | 数据来源 | 约束规则 |
|---------|---------|---------|---------|---------|---------|
| 重大危险源编号 | 文本 | 是 | 备案编号/内部编号 | 台账 | 唯一 |
| 在线监测指标与接入状态 | 列表 | 是 | 指标点与数据源标识 | 监测系统 | 至少含核心指标 |
| 定期检测评估记录索引 | 外键 | 是 | 报告/记录附件索引 | 附件/记录 | 有效外链 |
| 应急预案与处置卡外键 | 外键 | 是 | 预案与现场处置卡引用 | 外部模块 | 只读引用 |
| 备案信息 | 复合 | 是 | 部门、日期、系统ID | 备案记录 | 字段齐全 |
| 状态 | 枚举 | 是 | 在册/变更/核销 | 外部流程同步 | 只读显示 |
- 页面操作：编辑基础信息、维护附件、打开外部模块链接（演练/变更/核销/隐患）
- 交互说明：状态与外部流程结果自动同步；外部模块链接以只读卡片展示核心摘要

### 3.3 新建/编辑页
- 页面类型：表单页
- 页面目标：完成重大危险源的新增与信息更新
- 页面布局：顶部分组表单（基础信息、包保与公示、监测接入、备案信息）+ 右侧必填校验提示
- 字段设计（必填集）：

| 字段名称 | 字段类型 | 是否必填 | 字段说明 | 数据来源 | 约束规则 |
|---------|---------|---------|---------|---------|---------|
| 所属单元 | 下拉 | 是 | 生产/储存/使用/搬运 | 字典（GB18218） | 固定枚举 |
| 危险化学品名称与CAS/类别 | 复合 | 是 | 名称+CAS+类别 | 台账/字典 | 标准格式 |
| 最大库存/最大操作量 | 数值 | 是 | 上限数据 | 手动输入 | 非负、单位一致 |
| 临界量与判定结论 | 计算 | 是 | 根据规则计算 | 规则引擎 | 只读/回填 |
| 风险等级 | 枚举 | 是 | 四色图映射 | 字典 | 规则联动 |
| 三类包保责任人 | 复合 | 是 | 姓名、职务、联系方式 | 组织通讯录 | 三类必填 |
| 公示牌位置与照片 | 附件 | 是 | 现场照片 | 上传 | 至少1张 |
| 承诺公告链接/附件 | 文本/附件 | 是 | 公告材料 | 上传/链接 | 有效URL/文件 |
| 在线监测指标与数据源 | 列表 | 是 | 指标点/数据源标识 | 监测系统 | 至少含核心指标 |
| 备案信息 | 复合 | 是 | 部门/日期/系统ID | 备案记录 | 字段齐全 |
- 页面操作：保存、取消、必填校验、自动计算、预览
- 交互说明：
  - 判定结论由规则自动计算回填；保存前必须通过必填与格式校验
  - 保存后触发“状态=在册”，并同步备案信息（如更新）

### 3.4 在线监测与预警页
- 页面类型：列表/看板
- 页面目标：查看监测点状态与告警摘要，进入处置记录引用
- 页面布局：顶部筛选（指标/阈值状态/企业/单元）+ 指标卡片/表格 + 告警时间线
- 字段设计：

| 字段名称 | 字段类型 | 是否必填 | 字段说明 | 数据来源 | 约束规则 |
|---------|---------|---------|---------|---------|---------|
| 指标名称 | 文本 | 是 | 压力/液位/温度/流量等 | 监测系统 | 标准字典 |
| 阈值 | 数值 | 是 | 告警阈值 | 监测系统/配置 | 非负 |
| 当前值 | 数值 | 是 | 实时数据 | 监测系统 | 只读 |
| 告警状态 | 枚举 | 是 | 正常/预警/告警 | 监测系统 | 色彩映射 |
| 最近告警时间 | 日期时间 | 否 | 最新一次告警时间 | 监测系统 | 合法时间 |
| 处置记录引用 | 外键 | 否 | 处置记录外链 | 外部/隐患模块 | 只读引用 |
- 页面操作：查看趋势、导出报表、打开处置记录引用
- 交互说明：告警状态色标联动；阈值展示为只读，配置动作按角色授权（技术负责人）

### 3.5 包保履职记录页
- 页面类型：列表/表单
- 页面目标：记录每周/每季排查与履职情况，关联隐患整改
- 页面布局：顶部检索（责任人/时间/企业/单元）+ 记录表格 + 新增记录抽屉
- 字段设计：

| 字段名称 | 字段类型 | 是否必填 | 字段说明 | 数据来源 | 约束规则 |
|---------|---------|---------|---------|---------|---------|
| 责任人类别 | 枚举 | 是 | 主要/技术/操作 | 字典 | 固定枚举 |
| 排查时间 | 日期时间 | 是 | 周/季记录时间 | 手动输入 | 合法时间 |
| 排查范围 | 文本 | 是 | 涵盖装置/区域 | 手动输入 | ≤200字符 |
| 问题数量 | 数值 | 否 | 本次发现问题数 | 自动统计 | 非负 |
| 隐患条目引用 | 外键 | 否 | 隐患记录外链 | 隐患模块 | 只读引用 |
| 整改完成率 | 数值 | 否 | 关联隐患闭环率 | 隐患模块 | 0–100% |
- 页面操作：新增记录、编辑记录、导出、打开隐患引用
- 交互说明：频次提醒（周/季）通过消息/看板提示；整改动作在隐患模块完成

### 3.6 详情页内引用区：状态变更与核销
- 页面类型：只读引用视图
- 页面目标：展示外部“变更管理/核销”流程结果并同步台账状态
- 页面布局：状态摘要卡（当前状态、外部流程ID、最新审批结果、完成时间）+ 跳转按钮
- 字段设计：

| 字段名称 | 字段类型 | 是否必填 | 字段说明 | 数据来源 | 约束规则 |
|---------|---------|---------|---------|---------|---------|
| 当前状态 | 枚举 | 是 | 在册/变更中/核销中/已核销 | 外部流程同步 | 只读 |
| 外部流程ID | 文本 | 是 | 变更/核销流程ID | 外部模块 | 唯一 |
| 最新审批结果 | 文本 | 否 | 通过/驳回/整改 | 外部模块 | 只读 |
| 完成时间 | 日期时间 | 否 | 最新完成时间 | 外部模块 | 合法时间 |
- 页面操作：打开外部流程详情（新窗口/新标签）
- 交互说明：不在本模块承载任何审批或办理动作，仅显示与同步

### 3.7 详情页内引用区：隐患 / 应急预案与演练
- 页面类型：只读引用视图
- 页面目标：集中展示关联记录的摘要并支持跳转
- 字段设计（示例）：

| 字段名称 | 字段类型 | 是否必填 | 字段说明 | 数据来源 | 约束规则 |
|---------|---------|---------|---------|---------|---------|
| 记录ID | 文本 | 是 | 外部记录ID | 外部模块 | 唯一 |
| 标题/名称 | 文本 | 是 | 记录标题 | 外部模块 | ≤100字符 |
| 当前状态 | 枚举 | 是 | 在办/已完成/整改中 | 外部模块 | 只读 |
| 责任人 | 文本 | 否 | 当前责任人 | 外部模块 | ≤50字符 |
| 完成时间 | 日期时间 | 否 | 完成/演练时间 | 外部模块 | 合法时间 |
- 页面操作：打开外部记录详情
- 交互说明：本模块不提供新增/编辑/审批动作

## 5. 补充说明
- 数据字典：
  - 单元类型（生产/储存/使用/搬运，GB18218）
  - 危险化学品类别（GB18218）
  - 风险等级（四色图）
  - 包保责任人类别（主要/技术/操作）
  - 监测指标标准字典（压力、液位、温度、流量、气体浓度等）
- 业务规则：
  - 重大危险源判定由规则引擎依GB18218自动计算并回填
  - 判定为重大危险源后，强制要求包保责任配置、公示与承诺公告
  - 备案信息为必填并需与属地登记系统一致
  - 状态字段只读并由外部流程结果同步
- 非功能性需求：
  - 操作留痕与版本记录、附件长期留存
  - 列表查询性能优化、导出支持≥10万条（分批）
  - 权限与字段级校验，敏感字段脱敏展示
- 后续扩展：
  - 看板增强（风险态势、预警趋势、履职达标率）
  - 与地方统一监测平台的标准化接口适配
  - 多企业汇总与集团侧督办规则配置
