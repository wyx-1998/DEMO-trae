# 建设项目管理模块

## 概述
建设项目管理模块用于管理建设项目的全生命周期,包括项目的创建、进度跟踪、安全管理资料维护等功能。

## 页面列表

### 1. 建设项目列表.html
建设项目列表页面,提供项目的查询、查看、编辑、删除等功能。

**主要功能:**
- **Tab切换**: 支持按项目状态切换(建设中、已竣工、申报中、草稿)
- **搜索功能**: 支持多条件搜索,可展开/收起更多搜索条件
- **批量操作**: 支持批量删除、导出功能
- **表格展示**: 展示项目的详细信息,包括项目编号、名称、类型、状态、进度等
- **操作功能**:
  - 查看: 打开项目详情(只读模式)
  - 编辑: 打开项目详情(编辑模式)
  - 更新项目进度: 弹窗快速更新项目进度
  - 上传安全管理资料: 弹窗上传相关资料
  - 删除: 删除项目(需二次确认)
- **分页**: 支持每页显示数量选择和页码跳转

**搜索条件:**
- 项目编号
- 项目名称
- 项目管理类型(EPC、EPCM、PC、C、EMC、DB、CM、PMC、其他)
- 建设类别(工业建筑、民用建筑、商用建筑)
- 建设性质(新建、扩建、改建、迁建、恢复、其他)
- 业主单位(发包方)
- 实施单位(承包方)
- 是否纳入安全管理(是/否)

### 2. 建设项目详情.html
建设项目详情页面,支持新建、编辑、查看三种模式。

**主要模块:**

#### 基本信息
- 项目编号(必填)
- 项目名称(必填)
- 统计年份
- 项目管理类型(必填)
- 建设类别(必填)
- 建设性质(必填)
- 项目投资(万元)
- 经纬度坐标(可链接到高德地图查询)
- 是否纳入安全管理(必填)
- 项目地址(长文本)
- 项目概况(长文本)
- 计划开工日期
- 计划竣工日期

#### 项目单位信息
采用表格形式展示:
- **项目单位**:
  - 业主单位(发包方)
  - 实施单位(承包方)
- **其他相关单位**:
  - 管理单位
  - 设计单位
  - 监理单位
  - 地勘单位

每个单位包含:组织类型、单位名称、项目负责人、联系方式

#### 项目进展
- 项目状态(建设中/已竣工)
- 实际开工日期
- 实际竣工日期
- 项目完成百分比(进度条+滑块)
- 当前进展阶段(长文本)

#### 项目安全管理资料
采用Tab+树形结构+文件列表的方式组织:

**Tab分类:**
1. 安全设施三同时
   - 设计阶段
   - 施工阶段
   - 使用阶段

2. 职业健康三同时
   - 可行性论证阶段
   - 设计阶段
   - 验收阶段

3. 消防三同时
   - 设计阶段
   - 验收阶段

4. 其他安全管理资料

**功能:**
- 上传附件: 支持批量上传文件
- 批量下载: 批量下载选中的文件
- 批量删除: 批量删除选中的文件
- 批量设置: 批量设置文件所属节点
- 查看: 在新窗口预览文件
- 下载: 下载单个文件
- 删除: 删除单个文件
- 搜索: 按文件名搜索

**操作按钮:**
- 取消: 返回列表页
- 保存草稿: 保存为草稿状态
- 提交审批: 当"是否纳入安全管理"选择"是"时显示,提交审批后自动创建建设项目组织
- 提交: 提交表单

**模式说明:**
- **新建模式**: 所有字段可编辑,用于创建新项目
- **编辑模式**: 所有字段可编辑,用于修改已有项目
- **查看模式**: 所有字段只读,右上角有"编辑模式"按钮可切换到编辑模式

## 弹窗组件

### 1. 更新项目进度弹窗
快速更新项目进度信息:
- 项目状态(建设中/已竣工)
- 实际开工日期
- 实际竣工日期
- 项目完成百分比(滑块+数字输入)
- 当前进展阶段(长文本)

### 2. 上传安全管理资料弹窗
上传安全管理资料:
- 类型选择(安全设施三同时、职业健康三同时、消防三同时、其他安全管理资料)
- 所属节点选择(根据类型动态显示)
- 附件上传(支持多文件上传)

- 动态加载:根据选择动态加载相关选项

## 业务流程

### 创建项目流程
1. 点击列表页"新建"按钮
2. 填写基本信息(必填项:项目编号、项目名称、项目管理类型、建设类别、建设性质)
3. 填写项目单位信息
4. 选择是否纳入安全管理
5. 点击"保存草稿"或"提交"按钮
6. 如果选择"是否纳入安全管理=是",可点击"提交审批"按钮
7. 审批通过后,系统自动创建建设项目组织

### 更新项目进度流程
1. 在列表页点击"更新项目进度"按钮
2. 在弹窗中填写最新的项目进度信息
3. 点击"保存"按钮更新进度

### 上传安全管理资料流程
1. 在列表页点击"上传安全管理资料"按钮
2. 或在详情页的"项目安全管理资料"模块上传
3. 选择资料类型和所属节点
4. 上传附件文件
5. 点击"确认"按钮完成上传

## 注意事项

1. **必填字段**: 项目编号、项目名称、项目管理类型、建设类别、建设性质、是否纳入安全管理为必填项
2. **审批流程**: 选择"是否纳入安全管理=是"的项目需要提交审批,审批通过后才会自动创建组织架构
3. **数据保存**: 编辑过程中可随时保存为草稿,避免数据丢失
4. **文件管理**: 安全管理资料支持按阶段分类管理,便于查找和维护
5. **权限控制**: 
   - 建设项目安全管理人员:可查看、更新项目进展、上传安全管理资料
   - 建设项目安全管理人员、领导:可查看所有项目信息
