# 危险化学品信息库 - 危险性分类优化说明

## 🔍 问题分析

### 原始设计问题

1. **字段重复冗余**
   - 新建页面同时存在`危险性分类`（多选下拉框）和`危险性类别`（文本输入）
   - 编辑页面仅显示`危险性类别`文本框，缺少`危险性分类`
   - 两个字段功能重叠，用户理解困难

2. **数据逻辑混乱**
   - `chem-std-data.js`中只有`危险性类别`字段
   - 新建页面的`危险性分类`多选框数据无法有效保存
   - MSDS第2章GHS分类与前端字段对应关系不清晰

3. **用户体验不佳**
   - 编辑页面缺少危险性分类编辑功能
   - 用户需要分别理解两个相似字段的含义
   - 数据展示不一致，容易造成困惑

## 🎯 优化方案

### 核心思路：字段合并 + 交互优化

1. **统一字段设计**
   - 将`危险性分类`和`危险性类别`合并为`危险性分类`单一字段
   - 采用"分类名称 + 类别级别"的组合格式
   - 示例："易燃液体,类别2; 皮肤腐蚀/刺激,类别1A"

2. **交互体验优化**
   - 提供可视化编辑器，支持添加/删除分类
   - 实时预览功能，即时显示组合结果
   - 自动同步到MSDS第2章GHS分类字段

3. **数据一致性保证**
   - 前后端数据格式统一
   - 自动解析和生成标准格式
   - 与MSDS结构无缝对接

### 3. 数据逻辑处理

#### 分类数据解析
```javascript
// 解析存储的分类字符串
const parseClassification = (classificationStr) => {
  if (!classificationStr) return [{ classification: '', category: '' }];

  return classificationStr.split(';').map(item => {
    const parts = item.trim().split(',');
    return {
      classification: parts[0] || '',
      category: parts.slice(1).join(',') || ''
    };
  });
};

// 构建存储的分类字符串
const buildClassification = (list) => {
  const validItems = list.filter(item => item.classification && item.category);
  return validItems.map(item => `${item.classification},${item.category}`).join('; ');
};
```

#### 实时预览功能

## 🚀 实施建议

### 1. 数据迁移方案
```javascript
// 旧数据迁移函数
const migrateOldData = (oldData) => {
  const { hazards, hazardCategory } = oldData;

  // 如果存在旧数据，进行转换
  if (hazards || hazardCategory) {
    const classificationList = [];

    // 处理危险性分类
    if (hazards) {
      const hazardsArray = Array.isArray(hazards) ? hazards : hazards.split(',');
      hazardsArray.forEach(hazard => {
        classificationList.push({
          classification: hazard.trim(),
          category: ''
        });
      });
    }

    // 处理危险性类别
    if (hazardCategory) {
      const categories = hazardCategory.split('/');
      categories.forEach((category, index) => {
        if (classificationList[index]) {
          classificationList[index].category = category.trim();
        }
      });
    }

    return {
      hazardClassification: buildClassification(classificationList),
      classificationList
    };
  }

  return {
    hazardClassification: '',
    classificationList: [{ classification: '', category: '' }]
  };
};
```
